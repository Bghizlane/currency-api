# Currency API

A simple Python currency converter that uses a REST API to retrieve exchange rates.

## Features

- Convert currencies
- Get real-time exchange rates
- User input
- Error handling
- Environment variables
- Clean project structure

## Technologies

- Python
- Requests
- REST API
- JSON
- python-dotenv
- Git
- GitHub
